# HWPX package fuzz seeds

[H0 Rust recipes](../crates/kordoc-hancom/tests/support/hwpx_fixture.rs).
Original hashes and provenance are in the
[H0 fixture record](../crates/kordoc-hancom/tests/support/README.md).

are present. The seeds live in `corpus/hwpx_package/`.
